#  NeuroVerse - Gamified E-Learning Platform

> **NeuroVerse** is a modern e-learning platform built with **React** that combines interactive learning, gamification, and progress tracking to create an engaging educational experience.

---

##  About the Project

**NeuroVerse** is a modern and interactive e-learning platform designed to make learning more engaging through gamification and intuitive user experiences.

The platform enables users to explore courses, complete quizzes, track their learning progress, and stay motivated with a clean, responsive interface. Built with a modular React architecture, NeuroVerse is designed to be scalable for future AI-powered features.

---

##  Features

-  Interactive Course Dashboard
-  Secure User Authentication
-  Structured Learning Paths
-  Quiz & Assessment Modules
-  Progress Tracking
-  Gamified Learning Experience
-  Fully Responsive Design
-  Fast and Modern React Interface
---

##  Tech Stack

- **Frontend:** React.js, CSS3
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Language:** JavaScript (ES6+)
- **API Testing:** Postman
- **Build Tool:** Vite
- **Version Control:** Git & GitHub

##  Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/NeuroVerse.git
```

### Navigate to the Project

```bash
cd NeuroVerse
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:5173
```
